# Base Frontend — UMKM Template

A **blank frontend base** (Vite + React + TypeScript) to start a new SPA from
scratch. Clean, strict TypeScript, one starter page — nothing else to strip out.

## Stack

- Vite + React 19 + TypeScript (strict)

## Quick start

```bash
bun install
bun run dev            # http://localhost:5173
```

## What's included

- `index.html` + `src/main.tsx` — app bootstrap
- `src/App.tsx` — a minimal starter page

Build with `bun run build`.
